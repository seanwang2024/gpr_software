# .mtd 文件分析（校正零偏 批处理伴随文件）

> 2026-08-23 · 分析对象: 批处理文件夹/*.mtd（另一软件生成, 非 RADAN）

## 1. 观测事实

| 项 | 结果 |
|---|---|
| 数量 | 5 个, 与每个批处理输出 .eic 一一对应（`<原名>_b01.mtd`） |
| 大小 | 全部 **16 字节**, 固定不变 |
| 内容 | **5 个文件字节级完全相同**（MD5: 8c23e675...） |
| 十六进制 | `01 00 00 00 | 0F 00 00 00 | 90 01 00 00 | 04 00 00 00` |

## 2. 结构解码（小端 DWORD × 4）

| 偏移 | 原始值 | 十进制 | 推测含义 |
|---|---|---|---|
| 0x00 | 0x00000001 | **1** | 操作步骤数 count（本次只做了 1 步: 校正零偏） |
| 0x04 | 0x0000000F | **15** | 操作类型 ID（15 = 校正零偏, 该软件私有编号） |
| 0x08 | 0x00000190 | **400** | 该操作的参数值（窗口宽度/校正量, 语义待实验确认） |
| 0x0C | 0x00000004 | **4** | 参数长度(4字节=DWORD) 或 记录尾标志 |

即推测记录格式:
```
[步骤数 N] + N × { [操作类型ID] [参数] [参数字节数/标志] }   → 共 4+12N 字节
N=1 → 16 字节 ✓ 与实测吻合
```

## 3. 关键结论

1. **是"操作记录"文件**：内容与具体数据文件无关（5 个不同数据、同一操作 → 字节完全相同），
   只记录"批处理做了什么"，不含文件头/道数/时间戳等任何文件信息。
2. **证实只做了校正零偏一步**：count=1, 单条操作记录。
3. **参数=400**：语义未知。候选: 零偏估计窗口(采样点, 数据每道512点 → 400 合理)/
   校正量数值/内部枚举。若每道 512 采样, "窗口宽度400采样点"是目前最合理的解释。
4. 该软件与 RADAN 体系无关（RADAN 处理记录写 DZT 头追加区/DZX, typeId 99=DC去除；
   此处是独立的 16 字节二进制清单, ID 空间也私有）。

## 4. 待验证实验（可确定语义）

1. **同一操作改参数**：校正零偏里把参数(窗口/数值)调一次再批处理 → 看 0x08 处 DWORD 是否随参数变化、
   变化规律（线性=就是该参数值）。
2. **多步操作**：叠加第二个处理(如滤波)再批处理 → 预期 count=2、文件变 28 字节（4+12×2）,
   可确认记录是"步骤数组"结构。
3. **不同操作单步**：只做另一种处理 → 0x04 处 ID 变化, 可建立该软件的 操作ID表（类似 DZX typeId 表）。
4. **零操作/纯复制**：若软件支持不处理直接批处理输出 → mtd 是否为 4 字节(count=0)或不存在。

## 5. 实验一：改"参数→天线100M"重跑批处理（2026-08-23 13:12）

| 项 | 结果 |
|---|---|
| 新 .mtd | 仍是 16 字节 `[1, 15, 400, 4]`, MD5 与上一批**完全相同** |
| 输出 .eic | 与原始数据不同（985,983/1,775,616 字节≈55% 差异, 首差@0x408 至文件尾） |

**结论**：
1. **天线参数不写入 mtd** → mtd 只记录"处理操作链"（做了什么操作+操作参数），
   不记录采集/仪器参数（天线频率等）。天线参数属于数据属性或处理内部系数，不进操作清单。
2. 输出确实被重算（eic 大面积变化）；EIC 首差在 0x408≈1024+8 → 疑似 1024 字节文件头+数据区
   （仅顺带观察, 未按约定深入分析格式）。
3. **局限**：上一批(13:02)输出已被同名覆盖, 无法对比"改天线前后两批输出是否相同"——
   即无法判断天线100M是否改变了校正零偏的计算结果。若需验证：两批输出放不同文件夹保留再 diff。

## 6. 当前对 mtd 的最终理解

```
mtd = 处理操作清单（批处理做了什么）, 与数据文件内容/采集参数无关
[步骤数] + 步骤×{[操作ID][参数][参数长/标志]}
已知: ID 15 = 校正零偏(参数400), 未含: 天线型号等采集参数
```
